## 📋 报告结构

每份报告遵循统一的分析框架，确保每一篇都独立、完整、可读：
```
① 现象描述  →  时间+地点+事实，只陈述客观现象
② 理论框架  →  用经济学理论拆解，指出核心概念
③ 数据验证  →  用公开数据或观察数据支撑分析
④ 商业启示  →  对创业/商业决策的启发
⑤ 一句话总结 →  把洞察浓缩为一句话
```
这个结构的每一环，都在训练一条完整的能力链：**发现问题 → 分析问题→ 输出结论**  这也是商业分析师的核心竞争力。

### 报告速览

#### 01 · 大食代退出北京

大食代（Food Republic）巅峰期在内地拥有40+门店，如今仅剩11家，不足巅峰三成。本文从**科斯定理**出发，分析"二房东"模式在商场自营能力增强、外卖渗透率突破30%、消费者追求体验化的三重冲击下走向终结的过程。

**一句话**：没有一种模式能永远躺赢——当你存在的理由消失时，努力也无法挽回。

#### 02 · 野人先生质价比与情绪价值的双重胜利

2026年夏天，国产意式冰淇淋品牌"野人先生"全国门店突破1600家。本文从**消费决策转变**（贝恩报告显示2026年是质价比元年）和**情绪经济崛起**两个维度，拆解其爆火背后的商业逻辑。

**一句话**：质价比不是便宜，而是让品质可感知、可见；情绪价值正在成为消费决策的核心维度。

#### 03 · 奈雪的茶定位两空

奈雪2026年上半年营收同比下滑13.1%，净亏9749万元。本文分析其陷入"高端不高端、平价不平价"两空境地的根本原因——没有真正的爆款单品，以及用咖啡的第三空间模型做茶饮的情绪生意。

**一句话**：当品牌失去定义自己的资格时，等待它的只有被市场定义。

#### 04 · 为什么现在奶茶都一模一样

我发现几乎每年春天，所有奶茶店都在同一时间上"樱花"和"山茶花"；到了夏天，又齐刷刷上"柠檬奶"和"荔枝"；秋天则必出"桂花"；冬天集体上"草莓"和"车厘子"。

**一句话**：2026年的奶茶行业，所有新品长得像同一杯，原因简单到一句话——上游只长那些食材，全行业只跟同一个爆款。

#### 05 · 沃尔玛中国换帅

9月22日，沃尔玛中国再变动了两个核心岗位，这别后藏着怎样的原因？

**一句话**：沃尔玛中国换帅，说到底是，靠信任赚钱的品牌，发现信任正在流失，于是把增长型人才换成治理型人才的战术调整。

## 🔍 方法论

这套分析框架脱胎于我的经济学训练和日常练习：

- **宏观经济学**：消费函数、价格弹性、总需求-总供给模型
- **行为经济学**：锚定效应、心理账户、损失厌恶、交易效用
- **产业经济学**：市场结构、交易成本、平台经济
